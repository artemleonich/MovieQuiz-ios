# MovieQuiz

Квиз-приложение про кино. Угадывай рейтинги фильмов из топ IMDb — отвечай «Да» или «Нет» на вопросы вроде «Рейтинг этого фильма больше 6?».

## Как работает

- 10 вопросов за раунд, на каждый — постер фильма и вопрос про его рейтинг
- Нажимаешь «Да» или «Нет» — рамка подсвечивается зелёным (правильно) или красным (неправильно)
- Через секунду автоматически идёт следующий вопрос
- В конце раунда — алерт с результатом и кнопкой «Сыграть ещё раз»
